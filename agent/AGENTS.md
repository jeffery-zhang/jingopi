# Pi 全局指令

- 按用户要求全权操作 GitHub，优先使用已授权的 `gh` CLI。
- 中文回复，尽量简短。
- 修改前先检查上下文，修改后运行相关验证。
- 禁止在 `bash` 中调用 `apply_patch`；当前环境没有该命令，修改文件必须使用 Pi 提供的 `edit` 或 `write` 工具。
- 需要读取文件、搜索内容、查找文件或列出目录时，始终优先使用可用的 `read`、`grep`、`find`、`ls` 等专用工具；仅在专用工具无法满足需求时使用 `bash` 执行对应命令。
- 增删或变更 Pi 扩展（packages/extensions）及相关配置时，同步更新 README.md。
